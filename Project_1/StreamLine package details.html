AI & LangChain Packages

Packages used for AI agents, LLM integration, vector workflows, multimodal systems, and intelligent automation.

@langchain/core

Core foundation package of the LangChain ecosystem. It provides abstractions for prompts, chains, memory, tools, output parsers, and runnable pipelines.

KEY CONCEPT
LangChain helps developers create AI applications that combine LLMs with tools, memory, documents, and external APIs.
  • Used for AI agents
  • Prompt engineering workflows
  • Memory systems
  • Tool calling pipelines
  • AI orchestration
Feature Purpose
Chains Connect multiple AI operations
Memory Store conversational context
Tools Connect APIs and functions
💡
Alternative libraries include LlamaIndex, Haystack, and direct OpenAI SDK usage.

@langchain/google-genai

Integration package for Google's Gemini models inside LangChain. Used for text generation, vision models, structured outputs, embeddings, and multimodal AI systems.

gemini.js 
import { ChatGoogleGenerativeAI } 
from "@langchain/google-genai"

const model = new ChatGoogleGenerativeAI({
  model: "gemini-1.5-pro",
  apiKey: process.env.GEMINI_API_KEY
})

@tensorflow/tfjs

TensorFlow.js allows machine learning models to run directly inside Node.js or browsers. It supports neural networks, image classification, pose detection, embeddings, and custom ML pipelines.

ML Tensor AI Vision

@vladmandic/face-api

Advanced facial recognition library built on TensorFlow.js. Used for face detection, age prediction, emotion recognition, and identity matching.

⚠️
Face recognition systems should implement privacy controls and consent management.
02

Media Processing Packages

Packages for image manipulation, video processing, optimization, and cloud media management.

sharp

High-performance image processing library for resizing, compression, format conversion, watermarking, and optimization.

Upload image
Resize using Sharp
Compress image
Store optimized file
🚀
Sharp is significantly faster than ImageMagick for many operations.

fluent-ffmpeg

Wrapper around FFmpeg used for video transcoding, trimming, compression, streaming, and thumbnails.

Use Case Operation
Compression Reduce file size
Streaming Convert to HLS/DASH
Thumbnail Extract video frames

cloudinary

Cloud-based media management platform used for storing, optimizing, and delivering images/videos globally.

WHY USE IT
Cloudinary automatically optimizes image formats, resolutions, and CDN delivery for performance.

@imagekit/nodejs

ImageKit SDK for backend image uploads, transformations, optimization, and CDN-based delivery.

  • Image resizing
  • Auto WebP conversion
  • CDN acceleration
  • Video optimization
03

Security & Authentication

Packages responsible for authentication, authorization, password hashing, request protection, and secure APIs.

bcrypt

Password hashing library used for securely storing passwords. Instead of saving plain text passwords, bcrypt stores irreversible hashes.

auth.js 
const hash = 
await bcrypt.hash(password, 10)

const valid = 
await bcrypt.compare(password, hash)

jsonwebtoken

Used for JWT authentication systems. Generates signed tokens for stateless authentication.

JWT Auth Security
⚠️
Never store sensitive data inside JWT payloads. Always set expiration times.

express-rate-limit

Protects APIs against brute force attacks and excessive traffic by limiting requests.

Feature Purpose
max Maximum requests allowed
windowMs Time interval
04

Backend & API Packages

Core backend development packages for Express APIs, middleware, routing, and request handling.

express

Minimal and flexible Node.js web framework used for APIs, middleware, routing, authentication, and backend systems.

server.js 
import express 
from "express"

const app = express()

app.get("/", (req,res)=>{
  res.send("Hello World")
})

app.listen(5000)

cors

Middleware that enables controlled cross-origin requests between frontend and backend.

KEY CONCEPT
Browsers block unauthorized cross-origin requests. CORS explicitly allows trusted origins.

cookie-parser

Parses cookies from incoming HTTP requests and makes them accessible through req.cookies.

multer

Middleware for handling file uploads using multipart/form-data.

Client uploads file
Multer processes request
Store locally or cloud
Save metadata to DB

morgan

HTTP request logger middleware for Express. Useful for debugging, monitoring, and analytics.

05

Database & Queue Systems

Packages for databases, job queues, caching, and distributed task processing.

mongoose

MongoDB ODM library for schema definition, validation, query building, middleware, and relationships.

user.model.js 
const userSchema = 
new mongoose.Schema({
  name: String,
  email: String
})
💡
Alternatives include Prisma, TypeORM, and native MongoDB driver.

ioredis

Redis client for Node.js used for caching, pub/sub messaging, session storage, and queue systems.

bullmq

Redis-based job queue library used for background processing, email queues, video encoding, and scheduled tasks.

Job added to queue
Redis stores queue
Worker processes task
Result stored

p-queue

Promise queue library used for concurrency control, rate-limited tasks, and sequential processing.

06

Realtime & Scaling Packages

Packages for realtime communication, parallel processing, and scalable Node.js systems.

socket.io

Realtime bidirectional communication library used for chats, notifications, multiplayer games, and live dashboards.

Realtime WebSocket Events

piscina

Worker thread pool library used for CPU-intensive tasks like AI inference, compression, image processing, and encryption.

⚠️
Avoid blocking the Node.js event loop with CPU-heavy operations. Use worker threads instead.

Validation & Utility Packages

Validation, configuration, utility, and developer productivity tools.

express-validator

Validation middleware for Express APIs. Used for validating request body, params, and query values.

validation.js 
check("email")
  .isEmail()
  .withMessage("Invalid Email")

dotenv

Loads environment variables from .env files into Node.js applications.

uuid

Generates unique identifiers used for users, sessions, orders, tracking systems, and distributed IDs.

zod

Type-safe validation library used heavily in TypeScript applications. Provides schema validation and parsing.
